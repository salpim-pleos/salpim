# spike

1. `docs/spikes/Sx.md`를 연다 (템플릿 유지).
2. 각 섹션을 채운다:
   - **확인한 사실**: 직접 확인한 것만. 출처마다 [확인됨]/[미확인] 표기
   - **근거 링크**: 공식 문서 URL, SDK 소스/KDoc 경로, 에뮬레이터 버전. 제3자 글이면 그렇다고 명시
   - **결정**: 코드/범위에 미치는 결정
   - **못 확인한 것**: 시도했지만 확인 못 한 것을 그대로 쓴다. 추측으로 채우지 않는다
3. 상태 줄을 `미착수` → `진행 중` / `완료` / `막힘(대안 적용)`으로 바꾼다.
4. 후속 반영:
   - 코드의 `TODO(spike-Sx)` 위치를 grep해서 해결 가능한 것을 목록으로 사용자에게 보여 준다 (SDK 호출은 `core/signal`에만)
   - 막혔으면 AGENTS.md 5절의 "막히면" 대안을 적용하고 `docs/planning.md`(남은 일)와 README "현재 한계"를 갱신한다 (예: S2 실패 → 코어 F2→F3)
5. SDK 클래스/메서드 이름은 확인한 그대로만 적는다. 문서에 없는 이름을 만들지 않는다.
