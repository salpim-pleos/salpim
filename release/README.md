# 시연용 APK와 영상

공모전 심사가 익명이라, 업로드한 계정이 페이지에 표시되는 GitHub Releases 대신 이 폴더에 커밋해 둡니다 (커밋 작성자는 익명).

| 파일 | 내용 |
|---|---|
| [salpim-release.apk](salpim-release.apk) | 서명된 release APK (minSdk 28). 자동차 기기면 Pleos Vehicle SDK 신호, 아니면 시뮬레이션 신호로 동작 |
| [salpim-demo-simulation.mp4](salpim-demo-simulation.mp4) | 시연 영상 약 1분 30초, 소리 없음. 일반 Android 에뮬레이터(API 34)에서 시뮬레이션 신호로 녹화 |

영상은 **운전자와 살핌이 말을 주고받는 흐름**입니다. 에뮬레이터에는 마이크 입력이 없어 운전자의 말은 음성 인식 결과와 같은 경로로 넣었고, 화면 아래 음성 바에 "나"(운전자)와 "살핌"(대답)으로 남습니다. 화면에 "시뮬레이션 신호"가 항상 표시되고, 주행 화면 왼쪽 길 그림은 실제 내비 자리를 나타낸 시연용 그림입니다.

1. 주차 — 내 차 상태 6곳 정상. 나: "인천공항 가 줘" → 살핌: "인천공항으로 안내할게요."
2. 출발 — 길 그림이 움직이고 경로가 잡히면(52km) 연료가 모자라다고 살핌이 먼저: "이대로 가면 가는 길에 주유해야 해요. 주유소를 찾아 드릴까요?"
3. 나: "어디서 넣어?" → 살핌: "가는 길에 있는 주유소 중 서남주유소가 리터당 1,659원으로 가장 싸요. 안내할까요?" → 나: "응" → 경유지로 안내 (가격은 샘플)
4. 가는 길에 엔진오일 경고 — 아이콘이 노랗게 켜지고 살핌이 한 줄: "엔진오일이 부족해요. 정차 후 점검하세요." → 나: "계속 달려도 돼?" → 살핌: "당장 멈출 필요는 없지만 가까운 시일 안에 점검받으세요."
5. 주유소에 정차 — 할 일 칩(엔진오일 · 주유)과 블루핸즈 안내·휴대폰 예약 버튼
6. 나: "가까운 블루핸즈 찾아 줘" → 광희점 1.8km 외 2곳 → "첫 번째로 가 줘" → "예약할래" → 공식 예약 페이지 QR

장소는 서울시청 기준 **샘플 목록**입니다 (실제 주소, 거리는 서울시청에서 직선거리, 영업 여부 미확인, 주유 가격은 샘플 값 — `feature/service/src/main/assets/nearby_places_sample.json`).

Pleos 에뮬레이터에서 시연 시나리오를 쓰려면 `./gradlew assembleRelease -Psalpim.signalSource=sim`으로 빌드합니다. 녹화 방법은 `app/src/androidTest/.../DemoWalkthroughTest.kt` 주석에 있습니다.
