# S3. 속도/기어/주차브레이크 소스

- 상태: 문서 조사 완료 — **Pleos Vehicle SDK에 속도·기어·주차브레이크 API 없음**. AAOS 표준 경로는 에뮬레이터에서 확인 필요
- 조사일: 2026-11-09
- 막히면: 속도가 없으면 F3를 조향·페달 이벤트 중심으로 축소

경로 줄임: `…/Vehicle/`, `…/api/`는 S2와 같음

## 확인한 사실 [확인됨(문서)]

- **Brake** (권한 `CAR_DRIVE`): `getCurrentBrakePedalStatus` → `Boolean?`, `registerBrakePedalStatus(listener: BrakePedalStatusListener)`, `checkBrakePedalStatusCapabilities`
  - intro 표는 "brake pedal and **parking brake** states"라고 쓰지만 API 레퍼런스에 **주차브레이크 메서드 없음**
- **DrivingMode**: `getCurrentDrivingModeState` → `DrivingModeType?`, 크루즈 상태, `getCruiseControlTargetSpeed`. **차속·기어 없음**
- Vehicle SDK 전체에서 vehicle speed / gear / parking API를 찾지 못함
  - 공식 샘플 manifest에 `pleos.car.permission.CAR_SPEED` 선언은 있으나 사용 코드 없음
- **조향** (권한 `CAR_DRIVE`): `getCurrentSteeringWheelAngle(onComplete: (Float?) -> Unit, …)`, `registerSteeringWheelAngle(listener: SteeringWheelAngleListener)`, `checkSteeringWheelAngleCapabilities(…AreaBounds<Float>…)`
  - **값은 핸들 회전각이 아니라 앞바퀴 조향각**: "front-wheel steering angle in degrees … Leftward negative … does not represent the rotation angle of the steering wheel"
- API Compatibility 페이지: AAOS 프로퍼티 목록 없음. "VehiclePropertyIds/CarPropertyManager로 실제 지원 확인", "차종명으로 분기 금지", "SDK에 없는 특수 프로퍼티는 기술지원팀 검토 요청"
- 초기화: `val vehicle = Vehicle(context); vehicle.initialize(); val door = vehicle.getDoor(); … vehicle.release()`. 비동기 콜백 완료 전 `release()` 금지

## 결정 (제안 — 사용자 결정 대기)

1. 속도·기어·주차브레이크는 **AAOS 표준 `CarPropertyManager`**(`PERF_VEHICLE_SPEED`, `GEAR_SELECTION`, `PARKING_BRAKE_ON`)로 읽는 경로를 `core/signal`에 추가하고, S1 이후 에뮬레이터에서 읽히는지 확인. 안 되면 기술지원팀 문의
2. 그 경로가 막히면:
   - 주행 상태 판정은 `CarUxRestrictions`(주행 제한 상태) + 브레이크 페달을 조합 (현재 `UxPolicy`가 이미 시스템 제한을 우선 반영)
   - F3 급가속/급제동은 SIMULATED로만 시연, 실제 신호 F3는 브레이크 페달 on/off·앞바퀴 조향각 변화율 중심으로 축소
3. 급조향 임계값(`HabitConfig.sharpTurnDeg = 90`)은 핸들각 기준이라 **바퀴각 기준으로 다시 정해야 함** (바퀴각 범위는 훨씬 작음)

## 못 확인한 것

- Pleos 차량/에뮬레이터에서 `PERF_VEHICLE_SPEED`, `GEAR_SELECTION`, `PARKING_BRAKE_ON` 읽기 가능 여부, 필요한 권한
- `CAR_SPEED` 권한의 대응 API
- 에뮬레이터 VHAL 주입 가능 여부 (S4)
