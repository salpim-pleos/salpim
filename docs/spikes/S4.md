# S4. 에뮬레이터/Virtual Console 신호 주입

- 상태: 진행 중 — 문서 조사 완료, **에뮬레이터에서 직접 시도는 아직 안 함** (S1 이후)
- 조사일: 2026-11-09
- 막히면: SimulatedSignalSource로 시연

## 확인한 사실 [확인됨(문서)]

- **주행 규제 on/off** (문서상 "모든 차종 공통"):
  ```
  adb shell cmd hmg_car_service --service drivingstate driving_regulation on
  adb shell cmd hmg_car_service --service drivingstate driving_regulation off
  ```
- 기어 변경: adb 명령 없음 → Virtual Console 사용
- Change mode(유틸리티 모드): 조건 속도 0 + 주차 브레이크 ON + 기어 P, `/dev/vcs_simulator_rx`로 hex payload 전송 (페이로드는 문서에서 복사)
- CCS 명령은 에뮬레이터 미지원
- **Virtual Console 연결**: `adb forward tcp:8088 tcp:8088` → 브라우저 `http://127.0.0.1:8088/` → Emulation Controls
- Virtual Console 항목 (카드 48개 중 관련):
  - Motion: Gear Selection(P/R/N/D), Brake Pedal(0~100%), Odometer, Steering Angle(-540~540°)
  - ADAS: Cruise Target Speed 5.556~27.778 m/s (크루즈 설정값, 실제 차속 아님)
  - Safety: Telltales (주차브레이크, 안전벨트, ABS, TPMS 등) Off/On/Blink
  - Energy: SOC, 주행가능거리 등
  - **실제 차속 카드 없음**, **주차 브레이크는 경고등(telltale)으로만**, **타이어 압력 값 없음** (TPMS 경고등만)
- 주행 제한 개발 가이드에는 주입 방법 없이 `CarUxRestrictionsManager.registerListener()` / `onUxRestrictionsChanged()` 패턴만 있음

## AAOS 표준 (Pleos 문서 아님) [미확인]

- 커뮤니티 자료상: `adb shell dumpsys activity service com.android.car inject-vhal-event 0x11600207 <m/s>` (PERF_VEHICLE_SPEED). 공식 출처로 확인 못 함, Pleos 에뮬레이터에서 동작 여부 모름
- GEAR_SELECTION, PARKING_BRAKE_ON ID는 AOSP `VehicleProperty.aidl`에서 직접 확인 필요

## 결정

1. **UX 제한 검증**은 공식 `driving_regulation on/off`로 한다 → 시연/e2e 보조 스크립트로 추가 예정
2. **기어·경고·조향**은 Virtual Console로 주입 (Gear Selection, Telltales, Brake Pedal, Steering Angle)
3. `DrivingStateMachine`은 이미 기어만으로도 판정 가능 (속도 null이면 기어 D/R + 주차브레이크 해제 → DRIVING). 주차 브레이크·속도는 선택 입력으로 유지
4. **차속**은 S1 이후 `inject-vhal-event`를 직접 시도해 결과를 여기 기록. 안 되면 급가속/급제동은 SimulatedSignalSource로 시연하고 SIMULATED 배지로 구분
5. 항상 Cold boot

## 못 확인한 것

- 검색 요약에 보인 `dumpsys activity service com.android.car` 기반 VHAL 주입 절차, 차종별 블록, "-t 초 후 자동 해제" 옵션 — 현재 페이지에서 찾지 못함 (구버전 문서로 추정)
- 에뮬레이터에서 실제 차속·주차 브레이크 **상태**(telltale 아님)를 주입하는 공식 방법
- Telltale 조작이 Safety API 경고 값에 반영되는지 (S2와 연계, 앱에서 직접 확인 필요)
