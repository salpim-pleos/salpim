# S1. Pleos Connect 에뮬레이터 설치, 빈 앱 실행 (API 34 이미지, RAM 4GB)

- 상태: 진행 중 — 문서 조사 완료, **실제 설치/실행은 아직 안 함**
- 조사일: 2026-11-09 (공식 문서 열람)
- 막히면: 팀원 환경 비교, 공식 설치 문서 재확인

## 확인한 사실

모두 공식 문서에서 읽은 내용 [확인됨(문서)]. 실제 설치로 검증한 것은 없음.

- SDK Update Site: 이름 `Pleos Connect System Image`
  - Windows/Linux: `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
  - Mac(arm64): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-arm64-sys-img.xml`
- 사전 조건: 최신 Android Studio (버전 명시 없음), Android Emulator 요구사항 충족, 이전 Pleos 에뮬레이터 제거
- 설치: SDK Platforms → "Show Package Details" → **API 34**의 Pleos Connect 이미지 → 설치 후 Android Studio 재시작
- AVD: Device Manager → Create device → Form Factor **Automotive** → **Pleos Connect v2.1.0** → Advanced Settings: Default boot **Cold**, RAM **4 GB** → System image: API 34 "Pleos Connect v2.1.0 APIs"
- **Cold boot 필수**: 문서 원문 "If set to `quick boot`, VHAL cannot be used."
- Virtual Console은 에뮬레이터 2.1.0 이상 필요
- **외장 GPU 필요**: 권장 RTX 4060/5060 Laptop 8GB+ 또는 RX 7700S/7600M XT 8GB / 최소 RTX 3060 Laptop 6GB 또는 RX 6600M/6700S 8GB
- 기본 언어 한국어 (Vehicle Settings > General > Language)
- Bluetooth 동글 연동 미지원 (이 버전)
- 에뮬레이터 릴리스: v2.1.0 (2026-10-19). 추가: Virtual Console, 폼팩터 테스트 / 제거: LLM SDK, CRN, Bluetooth 동글
- minSdk 28 필수 (서명 키 로테이션/lineage 등 차량 사이버보안 요건)
- 새 프로젝트: Car/Automotive 템플릿, Kotlin, minSdk 28. 의존성 예시 `ai.pleos.playground:Vehicle:2.3.1`
- 값이 안 나올 때 확인 순서: minSdk → 권한 → sync → 부팅 상태 → `onFailed` 예외
- 앱 설치/실행: `adb install -d -r <apk>`, `adb shell am start -n <package>/<activity>`

## 결정

- `2.x` update site 사용, AVD는 v2.1.0 / API 34 / RAM 4GB / **Cold boot**
- 개발 PC GPU: NVIDIA GeForce RTX 5060, 시스템 RAM 16GB (2026-11-09 확인) → 권장 사양 충족으로 판단. (WMI가 보고하는 VRAM 4GB는 32비트 필드 한계라 실제 용량은 드라이버에서 확인)
- Android Studio 설치가 필요 (현재 PC에 없음). 설치 시 내장 JDK 17로 빌드 환경 문제도 해결

## 못 확인한 것

- 필요한 Android Studio 최소 버전, Windows Hyper-V/WHPX 관련 안내 (문서에 없음)
- 검색 결과에 옛 URL(`connect.v2.0.5_avd_x86_64/crp-sys-img.xml`)이 보였으나 현재 문서는 `2.x` URL
- 실제 설치·부팅·빈 앱 실행 (미수행)
