- 상태: 문서 조사 완료 — **원래 구상(경고등 전반 해설) 불가, 범위 축소 필요**. 에뮬레이터 값 확인은 S1 이후
- 조사일: 2026-11-09 (문서 기준 Vehicle SDK v2.3.2 / Vehicle Service v2.3.21)
- 막히면: 코어를 F2→F3로 전환하고 F2는 "향후 확장"으로 기획서 수정

경로 줄임: `…/Vehicle/` = `https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/Vehicle/`, `…/api/` = 그 아래 `vehicle/ai.pleos.playground.vehicle.api/`

## 확인한 사실 [확인됨(문서)]

### 서드파티가 쓸 수 있는 Safety API (권한 `CAR_SAFETY`, protection level normal)
| API | 반환 |
|---|---|
| `getEngineOilLevelState` | `OilLevelState?` |
| `getBrakeFluidLevelState` | `OilLevelState?` |
| `getTransmissionOilLevelState` | `OilLevelState?` |
| `hasLowWasherFluidWarning` | `Boolean?` |
| `hasPowerDownWarningIndicator` ("true이면 엔진에 문제") | `Boolean?` |
| `hasSeatBeltNotBuckledWarning(area: SeatArea, …)` | `Boolean?` |
| `hasSeatAirbagBeenDeployed(area: SeatArea, …)` | `Boolean?` |

- `OilLevelState` = `LOW`, `HIGH`, `NORMAL`, `ERROR`, `CRITICALLY_LOW`
- 구독: `registerXxx`/`unregisterXxx` → 리스너 `onXxxUpdated` (예: `registerEngineOilLevelState(listener: OilLevelStateListener)`). get/capability 결과는 `onComplete`/`onFailed` 비동기
- capability: `checkEngineOilLevelStateCapabilities(onComplete: (CapabilityConfig, List<OilLevelState>) -> Unit, …)` 등 항목별 `check…Capabilities`. `CapabilityConfig.accessType` = `NONE`/`READ`/`WRITE`/`READ_WRITE`

### 쓸 수 없는 것
- **경고등(telltale)**: `getTelltalesInfo`, `registerTelltales`, `checkTelltalesCapabilities`는 `PleosPermission.PRIVATE_CAR_SAFETY` (**signature|privileged**) → 서드파티 불가
  - 공식 샘플 `PublicApiPolicy.kt`도 `Safety.getTelltalesInfo/registerTelltales`, `Tire.getTirePressure/registerTirePressure`를 `blockedApis`로 막음
  - (참고) 모델: `TelltaleData(type, state, color, priority, warningCount)`, `TelltaleType`에 `TPMS`, `ABS`, `AIRBAG`, `ENGINE_OIL_PRESSURE`, `ENGINE_TEMPERATURE`, `MASTER_WARNING`, `PARKING_BRAKE`, `LOW_FUEL`, `SEAT_BELT` 등
- **Tire**: 공개 API는 `getLowTirePressure(area: WheelArea, …)` = "critically low tire pressure **threshold** in kPa" 뿐. 현재 공기압·경고 플래그 아님. `checkLowTirePressureCapabilities`

## 결정 (제안 — 사용자 결정 대기)

- F2는 유지하되 **공개 API 7종 기반으로 범위 변경**: 엔진오일·브레이크액·변속기오일 레벨, 파워다운 경고, 워셔액 부족, 안전벨트 미착용, 에어백 전개
  - 긴급도 예: `CRITICALLY_LOW`·파워다운·브레이크액 → `IMMEDIATE_STOP`, `LOW` → `SERVICE_SOON`, 워셔액 → `INFO`
- 현재 지식 베이스의 타이어·냉각수·충전·연료 등은 **실제 신호로 받을 수 없음** → 제거하거나 "향후 확장(권한 승인 시)"으로 표시
- 대표 시나리오를 "주행 중 타이어 경고" → "주행 중 엔진오일 부족(또는 브레이크액 부족)"으로 변경
- 안전벨트 미착용은 주행 중 시스템이 이미 경고하므로 중복 표시 여부 검토
