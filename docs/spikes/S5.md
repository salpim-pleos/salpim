경로 앞부분 `/p/` = `https://document.pleos.ai/en/docs/pleos-only/`

## 확인한 사실 [확인됨(문서)]

- 클래스 `ai.pleos.playground.navi.helper.NaviHelper`
- 초기화/해제: `NaviHelper(applicationContext)` → `initialize(onConnected, onFailed)` (인자 없는 `initialize()`도 있음) → `addListener()` → 종료 시 `removeListener(listener)` + `release()`
- **목적지 설정**: `naviHelper.requestRoute(RouteInfo(...))`, 확인 `getDestinationInfo()` → `onDestinationInfo`, 취소 `cancelRoute()`
  - `RouteInfo(latitude: Double, longitude: Double, displayLatitude: Double? = null, displayLongitude: Double? = null, poiName: String, poiId: String, address: String, poiSubId: String, routeOption: RouteOption = RouteOption.RECOMMENDED, poiProvider: String = "", isMobileRequest: Boolean = false)`
  - 진행 콜백: `onRouteStarted`, `onRoutingCompleted`, `onDestinationChanged`, `onError(errorCode)`
  - 문서: "A successful call to requestRoute() does not mean the route search is complete"
- **POI 검색 결과를 앱에 돌려주는 API는 없음** (메서드 전체 목록 대조)
- 대신 내비 화면 열기: `requestNavigationScreen(requestScreen: NavigationScreenRequest)`
  - 하위 타입: `SearchPlace(val keyword: String)` ("Place search screen"), `POIDetailPopup(poiId, poiProvider)`, `FavoriteMain`, `RecentDestinations`, `NearbyChargingStations` 등
- 즐겨찾기: `getBookmarkInfo()` → `onBookmarkInfo`, BookmarkType: DEFAULT, HOME, OFFICE, EV_CHARGING_STATION. 최근 목적지: `getRecentDestinationInfo()`
- 권한:
  - `pleos.car.permission.NAVI_ROUTE` — `get*Info()`, `requestTrip()`
  - `pleos.car.permission.NAVI_ROUTE_SEARCH` — `requestRoute()`, `cancelRoute()` 등
  - `pleos.car.permission.NAVI_CUSTOM_MAP` — `requestNavigationScreen()`
- 호환성: "NaviHelper SDK: Fully compatible only for vehicles equipped with navigation."
- 의존성: `ai.pleos.playground:NaviHelper:3.0.5` (S6)

## 결정

"정비소로 안내"는 두 경로 (정차·주차 화면에서만 노출):
1. **1순위** `requestNavigationScreen(SearchPlace("자동차 정비"))` — 내비 앱 검색 화면을 열고 사용자가 고른다. 권한 `NAVI_CUSTOM_MAP`
2. **2순위** 사용자가 지정한 정비소(위경도·이름·주소)로 `requestRoute(RouteInfo(...))`. 권한 `NAVI_ROUTE_SEARCH`
- SDK 호출은 `core/signal/navi`의 어댑터에만 둔다. `NavigationLauncher` 포트에 "검색 화면 열기"를 추가한다
- 내비 미장착 차량이면 버튼을 숨기거나 "내비가 없는 차량이에요"로 안내

## 못 확인한 것

- `requestRoute` 후 안내가 자동 시작되는지
- Intent 기반 대안
- `SearchPlace`로 연 화면에서 사용자가 고른 결과를 앱이 콜백으로 받는지
- 2순위에서 `poiId`/`poiSubId`를 빈 값으로 넣어도 되는지 (문서 예제는 `"36khp37hh8gqcm5nqhe5"` 같은 고유 ID) → 에뮬레이터에서 확인
