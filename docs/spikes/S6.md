### 권한
- 형식 `pleos.car.permission.{CONSTANT}`, 읽기 `CAR_*`, 제어 `CONTROL_CAR_*`
- `CAR_DRIVE`: DrivingMode, Brake, Odometer / `CAR_ENERGY`: EvBattery, Fuel / `CAR_SAFETY`: Safety, Tire / 그 외 `CAR_DOORS`, `CAR_INFO` 등
- 문서: 각 API의 `@RequiresPermission`을 확인할 것
- 공식 vehicle 샘플 매니페스트에는 표에 없는 `CAR_SPEED`, `CAR_TIRES`, `CAR_POWERTRAIN`, `CAR_MILEAGE`, `READ_CAR_STEERING`도 선언 (S3 관련, 정확한 대응 API 미확인)
- **"Declaring an unapproved permission or calling the corresponding API causes the app to fail app review."**

### SDK 공개 상태 (2026-11-09)
- 개요 페이지의 SDK: Vehicle, NaviHelper, SpeechToText, TextToSpeech, FusedLocation — 모두 좌표·버전 있음, 릴리스 노트(10/19)에도 있음. "coming soon" 표기 없음 → **이전 메모의 "TTS/STT/FusedLocation 준비 중"은 더 이상 맞지 않음**
- 호환성: TTS, STT "Fully compatible", FusedLocation "May vary by model" (`isSupported` 확인)
- TTS 권한 `pleos.car.permission.TTS_SERVICE`. 서버 모드는 `registerApp(clientID, clientSecret)` 필요, **ON_DEVICE 모드는 등록 불필요**
- Vehicle Control은 별도 SDK가 아니라 Vehicle SDK의 `setXxx` + `CONTROL_CAR_*` 권한
- LLM: API 레퍼런스만 있음 (`class LLM(context, mode: Mode = Mode.SERVER)`, `generateContent`, 권한 `pleos.car.permission.LLM_SERVICE`). 개요·릴리스 노트에 없고 설치 가이드 없음. 에뮬레이터 v2.1.0에서 LLM SDK 제거됨 (S1)

### 리뷰/디자인 규칙
- CarUxRestrictions로 UI 축소/비활성, 주행 중 영상 시작/재개 금지, 오디오는 Audio Focus Development Guide, 애니메이션 최소, 다단계 메뉴·키보드보다 프리셋·최근 항목·음성
- "Apply large touch targets, high contrast, and minimal text", "Follow the Pleos Connect UI Design Guide for button sizes and spacing" (링크된 basic-button 페이지에 dp 수치 없음)
- "Notifications unrelated to driving cannot be used", "Media apps must not post heads-up notifications"
- 개인정보·위치 사용 앱은 약관·데이터 처리 방침 제출 필요

## 결정

- Vehicle **2.3.1** 고정 (샘플·릴리스 노트 일치). 2.3.2가 저장소에서 받아지면 올린다. NaviHelper **3.0.5**
- 매니페스트: 우선 `CAR_DRIVE`, `CAR_SAFETY` + NaviHelper 권한(S5). 속도·타이어·조향 권한은 실제 `@RequiresPermission` 확인 후 추가 (미승인 권한은 반려)
- **TTS**: 공개됨, ON_DEVICE는 키 불필요. 단 주행 무관 알림 금지·오디오 포커스 정책 때문에 F2 `IMMEDIATE_STOP` 한정 선택 기능으로만 검토, Audio Focus 가이드 확인 전까지 **끈 상태** (안전/UX 규칙 3 유지)
- **LLM 사용 안 함** (오프라인 원칙, 설치 가이드 없음). STT는 범위 밖
- 개인정보 처리 방침 초안이 필요할 수 있음 → 기록은 기기 내 저장만, 위치 미사용

## 못 확인한 것

- 최소 터치 타깃 수치
- 네트워크 사용 관련 리뷰 규칙 (performance/security-privacy 페이지 미열람)
- TTS 사용 시 소리 알림 정책 세부, Audio Focus 가이드 내용
- 대회에서 LLM/STT 사용 허용 여부
- 권한 승인 절차 ("pre-negotiated and approved")의 구체 방법
- 저장소에서 실제로 의존성이 받아지는지 (빌드 미시도)
